# PhotoFree Photoshop — fond blanc au démarrage

Quand l'utilisateur ouvre la catégorie Photoshop, un document blanc de 1200 × 800 px apparaît automatiquement s'il n'y a pas déjà de document ouvert. Il est créé comme calque d'arrière-plan blanc. Les images peuvent ensuite être ouvertes ou ajoutées comme calques.

Installation : remplacez les fichiers du dépôt GitHub par ceux de cette archive, puis actualisez GitHub Pages avec Ctrl+Maj+R.
